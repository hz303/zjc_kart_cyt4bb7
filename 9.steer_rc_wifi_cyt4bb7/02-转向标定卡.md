## 2. 控制律（本次改动的核心）

```
u = Kp * err  +  U0 * sign(err)
    ‾‾‾‾‾‾‾‾    ‾‾‾‾‾‾‾‾‾‾‾‾‾‾
     细调(比例)    克服静摩擦与减速箱阻力(前馈)

err = 目标角 − 实测角     （单位：度）
err 先过死区（±0.2°），死区内 err = 0 ⇒ U0 也不加 ⇒ 静止不抖
```

**为什么不用 PI**：旧的 PI 是靠**积分爬到启动阈值**去顶静摩擦。但直流电机 + 减速箱的静摩擦是
**Coulomb 型的常数非线性**，让积分去逼近它有两个副作用：

1. **启动延迟** —— 积分要爬好几拍才够力，方向盘"先愣一下再动"；
2. **一动就过冲** —— 静摩擦突降到动摩擦，那一堆积分值全变成过冲，还得靠反向积分慢慢退。

前馈直接把这份出力按误差符号给出去，于是**积分就不需要了** → 结构更简单、响应更干脆。

**参数表**（上位机「转向闭环」档案 ID 18~26）：

| ID | 名字 | 含义 | 默认 | 单位 |
|---|---|---|---|---|
| 18 | `steer_tgt` | 目标转角 | 0 | deg |
| 19 | `steer_kp` | 比例增益 | **0** | duty/deg |
| 20 | `steer_u0` | **静摩擦前馈** | **0** | duty |
| 21 | `steer_db` | 误差死区 | 0.2 | deg |
| 22 | `steer_umax` | 输出限幅 | **9000** ★ | duty |
| 23 | `steer_en` | 内环使能 | 0 | — |
| 24 | `minv_s` | 电机极性 | **1** ★ | — |
| 25 | `steer_slew` | 目标斜坡 | **0（关）** ★ | deg/s |
| 26 | `steer_lim` | 软限位 | 27 | deg |

> ★ **2026-10-15：`steer_umax` 默认由 3500(35%) 改成 9000(90%)**（用户拍板）。
>   这条不是"力气大一点"，而是**饱和门槛从 `|err| ≈ 6.3°` 抬到 `≈ 24.7°`**
>   （`(u_max − u0)/Kp`，`Kp=300 / u0=1600`）⇒ 从"超过 6.3° 就恒出 35%"
>   变成"**几乎全行程按 `Kp·err` 比例给力**"：前段明显更快、也明显更冲。
>   ⚠ 90% duty 是有刷电机 + DRV8701 的极限档，长时间堵转会烫；
>     且"顶死/无进展"告警的"饱和"判据是相对 `u_max` 的 95%（= 8550，要 `|err| ≥ 23.2°`），
>     **比过去难触发得多**。想撤回：把 ID22 拖回 3500（在线、不用重烧）。

> ★ **2026-10-14：`steer_slew` 默认由 40 改成 0（关）** —— 照队友
>   （YINGYYUN/Karting-Project，commit `4ce6c93`「删除了舵机的目标斜坡」）的实车结论：
>   本环是**纯 P + 静摩擦前馈、没有积分器**，阶跃不需要"防裹死"；误差已被 ±27 软限位卡住，
>   `Kp·err` 直接顶到 `u_max` 才是"最快到位"。留着斜坡只剩**纯滞后**
>   （40 度/秒 ⇒ 0→27° 要 675 ms）。**滑条还在 0~200**，想研究斜坡随时拖回去。

> ★ **`steer_kp = 300` / `steer_u0 = 1600` / `minv_s = 1` 是队友在实车上验证过的值**
>   （`project/code/Param_Storage.c` 的 `DEFAULT_PARAMS` 末尾两项是 `300.0f, 1600.0f`）。
>   两边现在是**同一套硬件**（同引脚、同为脉冲+方向编码器），所以直接可用，不必从 0 试。
>   `minv_s = 1` 是为了让本工程的输出链等效于队友的 `SERVO_MOTOR_SIGN = -1`（推导见 `steer_ctrl.h`）。
>
> ⚠ **上电仍然全不使能**（`steer_en` 默认 0）⇒ 方向盘不会自己动；要动必须先打「转向|内环使能」。
> ⚠ ID 20/21 在 2026-10-07 **语义变了**（原来是 `steer_ki` / `steer_kd`），25/26 是新增的。
> 上位机若还留着旧存档，连上之后**点一次「恢复默认」**。

## 3. 第一步：先确认 SPI 通了（这一步没过，后面都别做）

烧录 → 接调试串口（**`UART_0` / 115200 / TX `P00_1` / RX `P00_0`**）→ 每秒多出一行：

```
        STEER tgt=0.00 delta=0.00 err=0.00 duty=0 raw=2157 en=0 flt=1
                                  ^^^^^^^^^^^^       ^^^^^^^^     ^^^^
                                  误差(度)            原始角       自检是否通过
```

**判据**（手去转方向盘，看 `raw`）：

| `raw` 的表现 | `flt` | 结论 |
|---|---|---|
| 稳定落在 0~4095，**转动方向盘时连续变化** | 1 | ✅ SPI 通了 → 进第 4 步 |
| **恒 0 或恒 4095/65535**，怎么转都不动 | 任意 | ❌ **SPI 没通** → 见 §3.1 |
| 数值乱跳、没有连续性 | 1 | ⚠ 多半是线太长 / 挨着动力线 → 先治线（双绞、远离电机线、就近共地） |

> ⚠ **`flt=0`（自检没过）不代表 SPI 断了**：SPI 主机自产时钟，从机不在时传输照样"完成"，
> 只是读回全 0 / 全 1 —— **判死活看 `raw`，不看 `flt`**。
> `flt=0` 更可能是"芯片型号不同、那组自检寄存器地址对不上"，此时读数仍可能可用。

### 3.1 SPI 不通时按顺序查

1. **CS 有没有接对**（`P07_3`）—— 这颗芯片靠 CS 选通，接错就是恒 0。
2. **MISO / MOSI 是否接反**（`P07_0` 是 MISO、`P07_1` 是 MOSI）。飞线最容易在这两根上踩。
3. **供电 3.3 V 实测**（万用表量，别信丝印）。
4. **看 `frame`**：`raw` 是 `frame >> 4` 的低 12 位。若 `raw` 恒 0 但 `frame` 在变，
   说明只是位段不同，改 `steer_abs.h` 的 `STEER_ABS_RAW_SHIFT` 试 0 / 8 / 16。
5. 把 `STEER_ABS_SPI_BAUD` 从 1 MHz 降到 **250 kHz** 再试（飞线长、边沿差时很有效）。

## 4. 核对中位与限位（**手推，转向电机别通电**）

`steer_abs.h` 里已经填了**队友实测值**：

| 量 | 值 | 位置 |
|---|---|---|
| 左限位原始读数 | **654.5** → `STEER_ABS_LEFT_RAW = 654` | 均值（15 次满幅摆动） |
| 中位原始读数 | **2157** → `STEER_ABS_MID_RAW = 2157` | 行程中点 |
| 右限位原始读数 | **3659.3** → `STEER_ABS_RIGHT_RAW = 3660` | 均值 |
| 每度计数 | **50.08** → `STEER_ABS_CNT_PER_DEG` | 行程 3004.8 计数 / 60 度 |

**核对动作**（保持 `en = 0`，手推方向盘）：

| 步 | 动作 | 期望读数 |
|---|---|---|
| ① | 推到**最左**（顶机械限位） | `raw ≈ 654`，`delta ≈ +30` 度 |
| ② | 推到**最右** | `raw ≈ 3660`，`delta ≈ -30` 度 |
| ③ | 回到**正中** | `raw ≈ 2157`，`delta ≈ 0` 度 |

>   按实测值改这三个宏；改完重编。**这是硬件事实，不能靠猜。**

## 5. 核对转向输出方向（默认已对齐队友，约 30 秒）

`minv_s`（上位机「转向|电机极性」）**默认 = 1**，已按队友那台对齐（理由见 §2 的 ★）。
所以正常情况下**不用调**，只要核对一次：

```
1) 「转向|内环使能」先打 1     ← 必须第一步
2) 「转向|目标转角」给 5 度左右
3) 看方向盘往哪边转、delta 是否朝目标走：
      朝目标方向走、err 在变小 → 正确，收工
      反着走（err 越走越大、可能直接打死）→ 立刻把 en 打 0，
          把「转向|电机极性」拖到 0，再试一次
```

⚠⚠ **第 1 步不能和第 3 步换。** 固件 `steer_ctrl_set_angle_enable()` 在使能的 **0→1 上升沿**
会用"**当前实测角**"重置目标（防一使能就朝旧目标猛打）——
**先给目标再使能，那个目标会被吞掉**，现象是"使能了但方向盘一动不动"。这是保护，不是故障。

## 6. 复核内环增益（默认已是队友验证值，这一步是"验"不是"标"）

### 6.1 直接用队友的值，看有没有异常

默认就是 `steer_kp = 300` / `steer_u0 = 1600`（队友实车验证值，两边同一套硬件）。

```
1) steer_en = 1
2) steer_tgt 从 0 → 5 → 10 度，逐步给（别一步就 30 度）
3) 看 steer_delta / steer_err / duty
```

| 现象 | 说明 / 调什么 |
|---|---|
| `delta` 平滑跟到目标，`err` 收敛到 ±0.2 度内 | ✅ 正常，收工 |
| 停住后 `delta` 离目标还差零点几度 | 正常残差（死区内）；想更准就把 `steer_db` 调小 |
| 一直嗡嗡抖 / 高频颤 | `steer_kp` 往下（先砍半：300 → 150） |
| 冲过头再回来（超调） | `steer_kp` 往下 |
| 起步"愣一下"才动 | `steer_u0` 往上加（每次 +100~200） |
| 稳态 `duty` 一直顶在 `steer_umax`（默认 9000） | 机械卡住，或 `steer_umax` 被拖小了 |

### 6.2 真要重标：顺序是"先 U0，再 Kp"

（只有在 §6.1 明显不对、或换了转向电机时才需要）

```
steer_kp = 0        ← 先把 kp 归零，只留前馈
steer_u0 = 从 0 慢慢往上加（步长 50~100）
```

**判据**：加到某个值，方向盘**"一颤一颤地几乎能动"**（轻轻推一下就顺着走）。
之后再 `steer_kp` 从 0 往上加，给台阶看响应：停不到位就加，超调就减半。

**对照量级**：

| 车 | U0 | Kp |
|---|---|---|
| **队友这台（同款机构，直接用）** | **1600** | **300** |
| 北极星队那台（机构不同，仅参考） | 静摩擦死区约 950 duty | 15（当时以计数为单位） |

### 6.3 最后看两个可选参数

| 参数 | 用途 | 什么时候调 |
|---|---|---|
| `steer_db`（误差死区，默认 0.2 度） | 静止时抑制抖动 | 静止有轻微嗡嗡 → 加到 0.3~0.5；但**太大就停不准**（0.5 度 ≈ 25 计数） |
| `steer_slew`（目标斜坡，**默认 0 = 关**） | 限目标变化率 | **默认就别动**（队友 2026-10-14 实测：没有斜坡响应更好、且不震荡）。只有在"某段机械特别涩、阶跃会把连杆撞响"时才往上加 20~60 度/秒试试 |

### 6.4 外环（航向）—— 当前**没接 IMU**，先别动

外环代码在 `steer_ctrl.c` 里写好了、默认关。要用需要：
1. 接 IMU，把每拍航向写进 `steer_yaw_deg`（`steer_ctrl.h` 里的全局变量）；
2. 调 `steer_ctrl_set_head_enable(1)`（会**连带开内环**）。

外环默认 `head_kp = 15`（度/度），本工程没有对应的上位机参数项。

## 7. 常见对不上

| 现象 | 原因 |
|---|---|
| `raw` 恒 0 / 恒满量程 | SPI 没通（CS、MISO/MOSI 反、供电、波特率） |
| `raw` 稳定但**不在 0~4095** | 位段不对 → 改 `STEER_ABS_RAW_SHIFT` |
| `raw ≈ 2157` 但 `delta` 不是 0 | `STEER_ABS_MID_RAW` 没对上本车 |
| **`delta` 读数 ±30 度但符号反** | `STEER_ABS_DIR_SIGN` 改成 `+1` |
| 一使能就打到死 | 电机极性反 → 翻 `minv_s` |
| `en=1` 但 `duty` 恒 0 | ① 目标就在当前位置（误差 0）；② 或 `steer_kp`/`steer_u0` 都还是 0 |
| `duty` 有值但方向盘不动 | `steer_u0` 不够（没顶过静摩擦）；或 `steer_umax` 被拖太小 |
| 使能了但目标被吞 | 正常的保护（见 §5 的 ⚠）→ 改成"先使能，再给目标" |
| 后轮速度环突然不对了 | 后轮编码器引脚见 §1.2 → 按 P17/P19 接线，重新标 `minv/inv/cpr` |
| 上位机参数名对不上 / 滑条拖了没反应 | 上位机还是旧档案 → 点一次「恢复默认」（ID 20/21 语义变了） |
