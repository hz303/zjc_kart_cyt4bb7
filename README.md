# zjc_kart_cyt4bb7

「**卡丁快跑**」组的预研工程 —— 在 **CYT4BB7** 上跑
**双后轮增量编码器闭环速度环**，并通过 **WiFi-SPI** 用 PC 上位机（KartHost）无线遥控、调参、看波形。

车端不接受"开环占空比"指令：**上位机只下发目标转速（rps）**。

```
        ┌────────────────────┐   WiFi-SPI   ┌──────────────────────────────┐
        │  KartHost (C#/Win) │ ◀──────────▶ │  CYT4BB7  CM7_0              │
        │  参数滑条 / 波形    │   固定协议    │  ├ spd_enc    测速            │
        └────────────────────┘              │  ├ spd_ctrl   速度环          │
                                            │  ├ spd_safety 五道保护门      │
                                            │  ├ motor_drv  双路 PWM/DIR    │
                                            │  └ steer_ctrl 转向位置环（9） │
                                            └──────────────────────────────┘
```

## 硬件接线（**工程 7**）

| 项 | 引脚 | 库里的名字 |
|---|---|---|
| 左电机 PWM / DIR | **P10_2 / P10_3** | `TCPWM_CH30_P10_2` / GPIO |
| 右电机 PWM / DIR | **P05_2 / P05_3** | `TCPWM_CH11_P05_2` / GPIO |
| 左编码器 脉冲 / 方向 | **P17_3 / P17_4** | `TC_CH58_ENCODER_CH1/2` |
| 右编码器 脉冲 / 方向 | **P19_2 / P19_3** | `TC_CH27_ENCODER_CH1/2` |
| 调试串口 | UART_0 @ **115200**（TX **P00_1** / RX **P00_0**）| — |

- 编码器引脚与库例程 `E2_01_encoder_dir_demo` 的「编码器1 / 编码器2」一致。
- 两路 PWM 同在 TCPWM0 GRP0，该组时钟分频共享 ⇒ **组内必须同频**（本工程都是 17 kHz）。

编码器为逐飞 1024 线 mini 增量式（**脉冲 + 方向**，不是正交），经电机轴 49 齿 → 27 齿增速：

> **每电机转 = 1024 × 49/27 = 1858 计数**（轮子与电机同轴，故也是每轮转计数）

## 控制律与增益

### 工程 7 / 工程 9 的**后轮速度环**（PI + 前馈）

```
u = u_ff(r) + k_v·(r − v) + k_z·∫(r − v)dt
u_ff(r) = r/K + u0·sign(r)
```

| 参数 | 值 | 说明 |
|---|---|---|
| `k_v` | **0.164** | 相位裕度 60°、α=6 反解后整体砍半 |
| `k_z` | **2.32** | 同上 |
| `duty_limit` | 默认 **30%**，硬顶 60% | 该芯片上唯一的输出硬约束 |

> ⚠ 车端真正生效的增益**以遥测 `k_v` / `k_z` 两列为准**（工程 9 起新增的"增益回读"通道）：
> 上位机滑条会按步长吸附、参数下发也曾按步长取整，**面板上的值不一定等于车上跑的值**。

### 工程 9 的**转向位置环**（纯 P + 静摩擦前馈，**没有积分器**）

```
u = kp·err + u0·sign(err)      err 先过 ±0.2° 死区、再受 ±27° 软限位与实际限位保护约束
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `steer_kp` | **300** duty/deg | 队友实车验证值 |
| `steer_u0` | **1600** duty | 静摩擦前馈（实测启动阈值约 1300~1600） |
| `steer_umax` | **9000**（90%） | ⭐ 决定"线性区到哪结束"：`(u_max − u0)/kp ≈ 24.7°` 才饱和 |
| `steer_slew` | **0（关）** | ⭐ 纯 P + 前馈环里目标斜坡只剩纯滞后 ⇒ 默认关（滑条 0~200 可在线打开） |
| `steer_lim` | **±27°** | 软限位（机械极限另有余量） |

> 实测依据与推理链：`9.steer_rc_wifi_cyt4bb7/00-工程9-遥控与引脚移植说明.md` §17 / §18。

## 保护（五道门，全过才允许出力）

1. 上电以来至少收到一帧下行
2. 使能位：`bit1` 电机 **且** `bit2` 总使能
3. 失联自停（超过 `lost_ms` 无下行 → 目标归零）
4. 主循环心跳（> 200 ms 没心跳 = 固件卡死 → 直接停机）
5. 占空比限幅（控制器夹一次，`motor_drv` 再夹一次）

门控不过时**输出严格 0 且清积分** —— 否则"被保护停住"期间误差一直累积，一放开门就是一次猛冲。
状态位图在遥测 `safety` 通道：`0x01` 没收到过下行 / `0x02` 未使能 / `0x04` 失联 /
`0x08` 无心跳 / `0x10` 配置非法 / `0x20` 本拍被限幅夹过。

> ⚠ **转向环不在这五道门里**，它有自己的一套（内环使能门控 + 软限位 + 越限保护 + 反馈失效锁存 +
> 顶死告警），且**不看心跳**：遥控不收 WiFi 影响。
> ⚠ 工程 9 里 `spd_safety` 的前三道门在"本机遥控接管"时会被换掉 ——
> 不插上位机也能开车，但**心跳 / 限幅两道门永不替换**。

## 上位机 KartHost

```sh
cd KartHost
dotnet build -c Release
bin/Release/net9.0-windows/KartHost.exe --selftest   # 自带 388 项语义自检
bin/Release/net9.0-windows/KartHost.exe              # 正常启动
```

- 参数滑条由**车端参数表**自动生成（X-Macro 驱动），**加通道/参数只往后加 ID**；
- 七个档案：卡丁车 / 单电机验证 / 双电机速度环 / 转向闭环 / 惯导+路表 / **卡丁·遥控** / **标定·精简**；
- 支持内置「模拟车端」、波形分图、`--shot-form` 出图 + 布局体检、CSV 录制与导出。

> ⚠⚠ **「档案」的通道数必须与车端遥测档（`tel_sel`）一致**，否则**通道名整体错位**
> （不报错、不越界，只是名字全挪位）。工程 9 起波形上会压一条**红警示条**并可**一键切到匹配档案**。
