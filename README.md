# zjc_kart_cyt4bb7

「**卡丁快跑**」组的预研工程 —— 在 **CYT4BB7**上跑
**左右双电机增量编码器闭环速度环**，并通过 **WiFi-SPI** 用 PC 上位机无线遥控、调参、看波形。

车端不再接受"开环占空比"指令：**上位机只下发目标转速（rps）**

```
        ┌────────────────────┐   WiFi-SPI   ┌──────────────────────────┐
        │  KartHost (C#/Win) │ ◀──────────▶ │  CYT4BB7  CM7_0          │
        │  参数滑条 / 波形    │   固定协议    │  ├ spd_enc   测速        │
        └────────────────────┘              │  ├ spd_ctrl  速度环 LQI  │
                                            │  ├ spd_safety 五道保护门 │
                                            │  └ motor_drv 双路 PWM/DIR│
                                            └──────────────────────────┘
```

## 硬件接线

| 项 | 引脚 | 库里的名字 |
|---|---|---|
| 左电机 PWM / DIR | **P10_2 / P10_3** | `TCPWM_CH30_P10_2` / GPIO |
| 右电机 PWM / DIR | **P05_2 / P05_3** | `TCPWM_CH11_P05_2` / GPIO |
| 左编码器 脉冲 / 方向 | **P17_3 / P17_4** | `TC_CH58_ENCODER_CH1/2` |
| 右编码器 脉冲 / 方向 | **P19_2 / P19_3** | `TC_CH27_ENCODER_CH1/2` |
| 调试串口 | UART_0 @ **115200**（TX **P00_1** / RX **P00_0**）| — |

- 编码器引脚与库例程 `E2_01_encoder_dir_demo` 的「编码器1 / 编码器2」一致。

- 两路 PWM 同在 TCPWM0 GRP0，该组时钟分频共享 ⇒ **组内必须同频**（本工程都是 17 kHz）。

编码器为逐飞 1024 线 mini 增量式（**脉冲 + 方向**，不是正交），经电机轴 49 齿 → 27 齿增速：

> **每电机转 = 1024 × 49/27 = 1858 计数**（轮子与电机同轴，故也是每轮转计数）

## 控制律与增益

```
u = u_ff(r) + k_v·(r − v) + k_z·∫(r − v)dt
u_ff(r) = r/K + u0·sign(r)
```

| 参数 | 值 | 说明 |
|---|---|---|
| `k_v` | **0.164** | 相位裕度 60°、α=6 反解后整体砍半 |
| `k_z` | **2.32** | 同上 |
| `duty_limit` | 默认 **30%**，硬顶 60% | 该芯片上唯一的输出硬约束 |



## 保护（五道门，全过才允许出力）

1. 上电以来至少收到一帧下行
2. 使能位：`bit1` 电机 **且** `bit2` 总使能
3. 失联自停（超过 `lost_ms` 无下行 → 目标归零）
4. 主循环心跳（> 200 ms 没心跳 = 固件卡死 → 直接停机）
5. 占空比限幅（控制器夹一次，`motor_drv` 再夹一次）

门控不过时**输出严格 0 且清积分** —— 否则"被保护停住"期间误差一直累积，一放开门就是一次猛冲。
状态位图在遥测 `safety` 通道：`0x01` 没收到过下行 / `0x02` 未使能 / `0x04` 失联 /
`0x08` 无心跳 / `0x10` 配置非法 / `0x20` 本拍被限幅夹过。

**上位机**（需要 .NET 9 SDK）：

```sh
cd KartHost
dotnet build -c Release
bin/Release/net9.0-windows/KartHost.exe --selftest   # 自带 130 项自检
bin/Release/net9.0-windows/KartHost.exe              # 正常启动
```

上位机档案选 **「双电机速度环」**；参数滑条由车端参数表自动生成，遥测 20 通道。
网络配置（SSID / 密码 / PC 的 IP / 端口）在 `code/motor_link.h` 第一节，**换网络只改前四行**。
