# 10 · Z 轴漂移的可能成因与验证方法

> 这里的“Z 轴漂移”指**航向角（yaw）随行驶累积的偏差**，不是车体垂直方向。
> 现象：直线 20 m 从 7° 到 7°；单方向多圈看着重合；但 S 弯/回环后 yaw 对不上。
> 本文给成因分类、判别矩阵、实验协议和补偿方案。

---

## 1. 结论先行

1. **直线 7°→7° 只能证明“静态零偏小”，不能证明没有 Z 轴漂移。**
   直线不转，陀螺比例误差、弯道左右不对称都不会被激励。
2. **单方向多圈重合，也不能排除左右不对称。**
   已有定圆数据：左 27° 的 `L_eff=0.677 m`，右 27° 的 `L_eff=0.659 m`，差 0.018 m；
   对应半径差约 **4 cm**，折算 **`b_asym≈0.38°`**。
3. **S 弯是最能暴露左右不对称的工况**：左弯和右弯的偏差同号，不会抵消。
4. 但 **S 弯漂移 ≠ 一定是左右不对称**。陀螺比例、静态零偏、转向 compliance、控制器饱和都能产生类似现象。
5. 一锤定音的实验是 **镜像 S（左先/右先）+ 反向 S + 多圈 figure-8**，不是再跑直线。

---

## 2. 现象与已有证据

| 观察 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 直线 20 m，yaw 7°→7° | 静态陀螺零偏/静态转向零偏很小 | 陀螺比例、弯道不对称、载荷相关 compliance |
| 单方向多圈轨迹重合 | 该方向半径稳定，重复性好 | 左右方向是否对称 |
| 左/右定圆 R=1.33/1.29 m | 存在约 4 cm 半径差 | 是轮胎、转向、陀螺还是路径 |
| `L_eff` 左 0.677 / 右 0.659 | `b_asym≈0.38°` 的初步证据 | 符号方向、是否随速度/转角变化 |
| S 弯后 yaw 对不上 | 左右不对称或比例/零偏 | 具体是哪一项 |

## 3. 成因分类

### 3.1 陀螺静态零偏 `b_gyro`

```
yaw_meas = yaw_true + b_gyro·t
```

- 直线就会漂；ZUPT/在线零偏可抑制；
- 你的 20 m 直线 7°→7° 基本排除**大的**静态零偏；
- 但 ZUPT 只在静止有效，行驶中的慢漂移仍可能残留。

**特征：** 误差随**时间**增长，不随左右方向翻转；镜像 S 后同号。

### 3.2 陀螺比例/安装误差 `s`

```
yaw_meas = (1+s)·yaw_true + b_gyro
```

- 直线不转 → 误差 0；
- 单方向圆 → 半径/航向增益偏一点，但看着仍是圆；
- 对称 S（左 +θ、右 −θ）→ 比例误差**抵消**；
- 不对称 S/回环 → 留残差；
- ZUPT 完全估不到它。

**特征：** 误差与**总转过角度**成比例；左右镜像后不翻符号；360° 慢转可直接测。

### 3.3 转向静态零偏 `b0`

```
δ_actual = δ_cmd + b0
```

- 直线会偏；ZUPT/直线标定可测；
- 你的直线 7°→7° 说明 `b0` 很小；
- 但只在**载荷/打角**下出现的 compliance 不是 `b0`。

**特征：** 直线和弯道都同号；镜像 S 同号。

### 3.4 弯道左右不对称 `b_asym`

```
δ_required = Lκ + Kus v²κ + b_asym·sign(κ)
```

- 直线看不到；
- 左/右同半径定圆半径不同；
- S 弯左、右段偏差同号，**不抵消**；
- 定圆已量出约 **0.38°**（27° 转角）。

**特征：** 镜像 S 后 `Δψ` 翻符号；左/右定圆 `L_eff` 不同。

### 3.5 轮胎/悬架左右不对称

- 轮胎锥度、胎压、主销偏置、左右 cornering stiffness 不同；
- 表现和 `b_asym` 几乎一样；
- 换胎/左右换轮后 `b_asym` 若变化，说明在轮胎侧。

**特征：** 与载荷/胎压相关；换轮实验可分辨。

### 3.6 转向 compliance / 载荷相关转角

- 转向柱/齿条/轮胎侧偏在横向载荷下变形；
- 传感器测的是转向柱角，实际前轮角随 `ay` 变化；
- 同一 `steer_deg`、不同速度，R 会不同；
- 可能是 R2.27 与 R2.75 那组 0.071 m 差异的来源。

**特征：** 误差随 `|ay|`、`v²κ` 增长；同一转角不同速度结果不同；不是常数 `b_asym`。

### 3.7 控制器/执行器左右差异

- 左右转向速率限幅、死区、回差不同；
- PP/LQR 在 S 弯换向时相位滞后；
- 饱和时左右可用转角不同。

**特征：** 只在饱和/快速换向时出现；看 `steer_cmd` vs `steer_act`、`sat` 标志。

### 3.8 航向估计/融合

- ZUPT 误触发、在线零偏把弯道误差学成零偏；
- 融合权重、路径/里程计修正；
- 记录的 `yaw` 已经是修正后的值，不是 raw gyro 积分。

**特征：** `yaw` 与 raw `gz` 积分不一致；ZUPT 标志/在线零偏在弯道有跳变。

### 3.9 路径/里程计

- 路表曲率左右不对称；
- `pb_elat` 是 odom 推算，不是外部真值；
- 最近点索引在 S 弯换向时跳变。

**特征：** 同一辆车、同一路线重复性差；换路表/换起点变化。

## 4. 定量：`b_asym` 能在 S 弯造成多大误差

对一段圆弧（转角 θ，转向角 δ）：

```
Δψ_extra ≈ b_asym · θ / δ
```

用 `b_asym=0.38°`、`δ=27°`：

| 圆弧 | 每段额外 yaw |
|---|---|
| 90° | 0.38 × 90/27 ≈ **1.3°** |
| 180° | ≈ **2.5°** |
| 一个 S（左 90° + 右 90°） | ≈ **2.6°** |
| 一个 S（左 180° + 右 180°） | ≈ **5.1°** |

这和你之前 1.3°~9.7° 的回环 yaw 误差是同一量级，所以**“S 弯放大左右不对称”在数量级上成立**。

> 注意：`b_asym` 可能随 δ、v、ay 变化，以上只是 27° 点的线性外推。

## 5. 为什么现有测试不够

| 测试 | 激励了什么 | 漏了什么 |
|---|---|---|
| 直线 20 m | 静态零偏 | 比例、弯道不对称、compliance |
| 单方向多圈 | 该方向半径/重复性 | 左右差异 |
| 左/右定圆 | `b_asym`、`L_eff` | 换向瞬态、S 弯累积 |
| 普通跑圈 | 综合 | 不可重复、不可分解 |

**S 弯/回环是“左右不对称”的放大镜，但不是“单一原因”的判据。**

## 6. 验证矩阵：一次实验分清主因

### 6.1 核心实验：镜像 S

```
S_LR：左 90° → 右 90° → 直线出
S_RL：右 90° → 左 90° → 直线出（镜像）
```

同一入口/出口直线，速度 1.5 / 2.0 / 2.5 m/s，各 5 次。

记录出口直线上的：

- `Δψ = yaw_exit − yaw_entry`
- `Δy =` 出口相对入口的横向偏移
- `∫gz dt`（raw gyro 积分）
- `steer_act`、`sat`

判据：

```
A = (Δψ_LR + Δψ_RL)/2      ← 左右共同的偏差（静态/比例）
B = (Δψ_LR − Δψ_RL)/2      ← 左右不对称
```

| 观察 | 结论 |
|---|---|
| `|B| >> |A|`，镜像后 `Δψ` 翻符号 | **`b_asym` / 左右不对称** |
| `|A| >> |B|`，镜像后同号 | 静态零偏/陀螺零偏 |
| 误差随总转角增大，镜像后抵消 | **陀螺比例 `s`** |
| 误差随圈数线性增长 | 每圈固定偏差（bias/asym） |
| 只在高 `ay`/大转角出现 | 转向 compliance/轮胎 |
| 只在 `sat=1` 出现 | 执行器/控制器左右限幅 |

### 6.2 反向 S

同一 S 反着跑（从出口到入口）：

- 如果 `Δψ` 随反向**翻符号** → 路径/车辆方向相关（asym）；
- 如果同号 → 时间相关（bias/scale）。

### 6.3 多圈 figure-8

左右各一圈，5~10 圈：

- 每圈 `Δψ` 是否累加；
- 左右交换顺序是否改变符号；
- 轨迹闭合误差是横向还是航向。

### 6.4 陀螺比例 360°

慢转整整 360°（转台/画圆/推车）：

```
s = (∫gz_raw dt / 360°) − 1
```

- 直线不转测不到；
- 单方向圆也测不准；
- 必须用**已知几何角度**做参考。

### 6.5 转向角左右一致性

原地/低速 ±10°/±20°/±27° 阶跃：

- `steer_act` 左右是否对称；
- 同一目标角，左/右实际角差多少；
- 这是 `b_asym` 的机械来源之一。

### 6.6 外部航向参考

至少在 S 入口/出口用：

- 地面标记/激光/全站仪；
- 手机指南针（仅粗查）；
- 双天线 GPS/RTK（如果有）。

不要只用 `ins_odom` 的 `yaw` 判断“车漂了还是估计器漂了”。

## 7. 数据处理公式

### 7.1 等效轴距

```
L_eff = v·tanδ / (−yaw_rate)
```

- 只在稳态、非饱和、`|δ|` 足够大时算；
- 左/右分别统计。

### 7.2 左右不对称

同一速度、同一 `|δ|`：

```
b_asym ≈ (L_eff_L − L_eff_R)/2 · |κ|
```

### 7.3 Kus

```
Kus = (L_eff − L)/v²
```

只在 `v>1.5 m/s`、稳态、非饱和时用；不要用瞬态数据。

### 7.4 比例误差

```
s = yaw_meas / yaw_geom − 1
```

`yaw_geom` 用已知 360° 或已知半径圆弧的几何角度。

### 7.5 静态零偏

```
b0 = (yaw_end − yaw_start)/Δt   （直线、无转向）
```

如果 `yaw` 已被在线估计修正，要用 raw `gz` 积分另算。

## 8. 判定流程

```
直线 20m yaw 不变？
 ├─ 是 → 静态零偏小；继续
 └─ 否 → 先查 ZUPT/静态 b0

左/右定圆 L_eff 差 > 0.01m？
 ├─ 是 → 有 b_asym 或轮胎/转向不对称
 └─ 否 → 查比例 s / 时间 bias

镜像 S：Δψ 翻符号？
 ├─ 是 → b_asym 主导
 └─ 否 → 静态 bias / 陀螺 scale

误差随总转角增大、镜像抵消？
 ├─ 是 → 陀螺 scale s
 └─ 否 → 载荷相关 compliance / 控制器
```

## 9. 补偿方案

### 9.1 `b_asym`

```
δ_cmd -= b_asym · sign(κ_ref)
```

或按方向用两套等效轴距：

```
左弯 L_eff_L，右弯 L_eff_R
δ_ff = atan(L_eff_dir · κ_ref)
```

### 9.2 陀螺比例 `s`

```
yaw_corr = yaw_meas / (1+s)
```

或对 `gz` 做比例修正；不要塞进静态零偏。

### 9.3 静态零偏

继续用 ZUPT/直线标定；只修**时间相关**的慢漂移。

### 9.4 载荷相关 compliance

用 `L_eff(v, |ay|)` 小表，而不是常数 Kus；需要更多定圆点。

## 10. 当前证据与下一步

**支持“左右不对称”的证据：**

- 左/右 27° 定圆 `L_eff=0.677/0.659`，差 0.018 m；
- 折算 `b_asym≈0.38°`；
- 数量级上能解释 S 弯 1~5° 的 yaw 误差。

**还不能定论：**

- R2.27/v2.05 组异常，说明还有速度/转角相关因素；
- 没有镜像 S，无法排除陀螺比例/静态零偏；
- `yaw` 是 odom 输出，需 raw `gz` 交叉验证。

**下一步：**

1. 按 §6.1 做镜像 S（1.5/2.0/2.5 m/s，各 5 次）；
2. 同一 S 反向跑；
3. figure-8 5~10 圈；
4. 同步记录 raw `gz`、`steer_act`、`sat`、ZUPT/在线零偏；
5. 用 §7 公式算 `b_asym`、`s`、`b0`，按 §8 判定。
