  - 旧：左轮 `P05_0`(PWM CH09) / `P05_1`(DIR) ＋ 右轮 `P05_2`(PWM CH11) / `P05_3`(DIR)
  - 新：左轮 `P05_2`(PWM CH11) / `P05_3`(DIR) ＋ 右轮 `P05_1`(PWM CH10) / `P05_0`(DIR)
  - 即"左右整体对调"，且 `P05_0`/`P05_1` 的 PWM/DIR 角色也互换了。
  - CYT4BB 的 P05 四个脚都能做 TCPWM（`P05_0=CH09 / P05_1=CH10 / P05_2=CH11 / P05_3=CH12`），
    **两种接法都能编译通过**，只能靠实际接线区分。
  - ⚠ **改完必须重核 `minv_l` / `minv_r`**（判据见 `motor_drv.h` 末尾）。
  - 转向 `P10_2/P10_3` 与两个后轮编码器 `P17/P19` **都没变**。

- ★★ **后轮编码器引脚 `P17/P19` 就是本车方案**（经用户确认）。`spd_enc.h` 原先误写成 `P08/P07`，
  注释里还说是"队友把 P17/P19 让给了 SPI 设备"；但查 `zf_driver_spi.h`：
  **SPI_4(SCB5) 的引脚范围只有 `P07_0 ~ P07_4`，根本不占 P17/P19** —— 那个说法是错的。
  已修正，而且**队友后来也采用了这套引脚**。
- ★ 两侧后轮编码器现在**都是脉冲+方向**（`encoder_dir_init`）。我们这台在 MM32 上实测确认过：
  同一个编码器的单路信号接进 x4（quad）会**相消、读数≈0**，所以必须走 dir 模式 ——
  别因为"正交更常见"就换回去。队友原本用正交，2026-10-07 也改成了带方向。
- ★★ **为什么电机也重排过**：队友为了接够 SPI 设备做了**飞线**。
  左后轮从 `P10_2/P10_3` 挪到 `P05_0/P05_1` ⇒ **腾出的 `CH30` 正好给转向电机**。
- ⚠ **`SPI_4`（SCB5）是逐飞库原本没有的第 5 条 SPI**，本工程照队友的改法扩了出来：
  `zf_driver_spi.c/h` 里加了 `SPI_4` 枚举、`SCB5` 实例映射、`PCLK_SCB5_CLOCK`、5 个引脚 case。
  顺手给逐飞**所有** SPI 忙等加了超时 —— 原来是**无限 `while`**，SCB 一出问题函数永不返回，
  一旦放进中断就是整车死（`SPI_BUSY_TIMEOUT` + `SPI_WAIT_UNTIL/WHILE`）。
- 三路 PWM 都在 TCPWM0；逐飞库把**所有**通道都挂到**同一个 16 位分频器**（80 MHz/10 = 8 MHz 源），
  频率 = 8 MHz / clockPrescaler / period，后两者每通道独立 ⇒ 同一条 TCPWM0 上可以不同频，
  但那一个分频器是共享的。本工程三路同为 17 kHz。
- 转向绝对编码器走 **SPI_4 / 1 MHz / MODE0**（飞线信号质量保守取值；波形干净时可提到 8 MHz）。
- dir 模式下 DIR 脚被库配成 **下拉输入**（`CY_GPIO_DM_PULLDOWN` + GPIO）。若编码器方向线是开集输出，
  悬空时电平会恒为 0 → 测速符号恒定，此时要把该脚改成上拉。

## 3. 控制律与参数

### 3.1 转向位置环（★ 本次换的）

```
u = Kp · err  +  U0 · sign(err)
    ‾‾‾‾‾‾‾‾     ‾‾‾‾‾‾‾‾‾‾‾‾‾‾
     细调(比例)      克服静摩擦与减速箱阻力(前馈)

err = 目标角 − 实测角（度）;  err 先过死区(±0.2°) ⇒ 死区内 err=0 ⇒ U0 也不加 ⇒ 静止不抖
```

**为什么不用 PI**：旧版靠**积分爬到启动阈值**去顶静摩擦。但直流电机 + 减速箱的静摩擦是
**Coulomb 型的常数非线性**，让积分逼近它有两个副作用：① **启动延迟**（积分要爬几拍才够力，
方向盘"先愣一下再动"）；② **一动就过冲**（静摩擦突降到动摩擦，攒的积分值全变成过冲）。
前馈把这部分出力按误差符号直接给出去，**积分就不需要了**。

| 参数（上位机 ID） | 含义 | 默认 | 单位 |
|---|---|---|---|
| 18 `steer_tgt` | 目标转角 | 0 | deg |
| 19 `steer_kp` | 比例增益 | **300** ★ | duty/deg |
| 20 `steer_u0` | **静摩擦前馈** | **1600** ★ | duty |
| 21 `steer_db` | 误差死区 | 0.2 | deg |
| 22 `steer_umax` | 输出限幅 | **9000** ★ | duty |
| 23 `steer_en` | 内环使能 | 0 | — |
| 24 `minv_s` | 电机极性 | **1** ★ | — |
| 25 `steer_slew` | 目标斜坡 | **0（关）** ★ | deg/s |
| 26 `steer_lim` | 软限位 | 27 | deg |

> ★ **带星号的三项是队友在实车上验证过的值**（`Param_Storage.c` 的 `DEFAULT_PARAMS` 末尾是
> `300.0f, 1600.0f`）。两边现在是**同一套硬件**（他把后轮正交编码器也改成了脉冲+方向、并采用了本车引脚），
> 所以直接可用。`minv_s = 1` 是为了让输出链等效于队友的 `SERVO_MOTOR_SIGN = -1`。
>
> ⚠ **上电仍然全不使能**（`steer_en` 默认 0）⇒ 方向盘不会自己动；要动必须先打「转向|内环使能」。
> ⚠ ID 20/21 在 2026-10-07 **语义变了**（原 `steer_ki` / `steer_kd`），25/26 是新增的 →
> 上位机旧存档请**点一次「恢复默认」**。

### 3.2 后轮速度环

```
u = u_ff(r) + k_v·(r − v) + k_z·∫(r − v)dt
u_ff(r) = r/K + u0·sign(r)
```

| 参数 | 值 | 来源 |
|---|---|---|
| K | **6.46** rps/占空比 | 本车台架 8 点稳态拟合（残差 ≤ 0.022 rps），另一组 4 点阶梯互证到 1% |
| u0 | **0.033** | 同上 |
| τ | ≈ 24 ms | 各平台阶跃拟合（13~33 ms） |
| 反馈等效延迟 | ≈ 10 ms | 4 点滑窗 7.5 ms + ZOH 2.5 ms |
| k_v / k_z | **0.164 / 2.32** | PM=60°、α=6 反解后整体砍半 |
| 闭环实测 | 稳态误差中位 **±0.01 rps** | MM32 台架，目标 0.5~1.5 rps |

> 这组数只对**这台驱动电机**（要装到卡丁后轮上的那台）成立。
> 项目里另一台「转向电机」K ≈ 215，差 33 倍，**一个数都不能互抄**。
> K 随负载变：空载 K 最大（稳定性最差工况），落地带载后 K 变小、u0 变大 → 前馈偏小由积分补足（偏保守）。
> **落地后建议重测一组稳态点回填。**

## 4. 编码器每转计数（cpr）

本车实测：编码器 **1024 线**（只数上升沿）+ 电机轴 49 齿带动 27 齿（增速 49/27）
⇒ **每电机转 = 1024 × 49/27 = 1858**（轮子与电机同轴，所以也是每轮转计数）。

标定：清零 `pos_l`/`pos_r` → 单方向手转**电机轴**整 10 圈 → `cpr = pos 增量 / 10`。

## 6. 保护（五道门，全部满足才允许出力）

| 门 | 判据 |
|---|---|
| 1 上位机说过话 | 上电以来至少收到过一帧下行（没有就绝不自己转） |
| 2 使能位 | `bit1`（电机）且 `bit2`（总使能）都置位 |
| 3 失联自停 | `auto_stop=1` 且链路超过 `lost_ms` 无下行 → 目标归零 |
| 4 主循环心跳 | 超过 200 ms 没心跳（主循环卡死）→ 直接停机 |
| 5 占空比限幅 | `duty_limit%` 压给控制器，`motor_drv` 里还有一道 `|u| ≤ 1` |

门控不过时**输出严格 0且清积分** —— 否则"被保护停住"期间误差一直累积，一放开门就是一次猛冲。
保护状态位图在遥测通道 `safety`（0 = 一切正常）：`0x01` 没收到过下行 / `0x02` 未使能 /
`0x04` 失联 / `0x08` 无心跳 / `0x10` 配置非法 / `0x20` 本拍被限幅夹过。
`0x04 / 0x08 / 0x10` 发生时主循环会打印一行 `[!!] SAFETY EVENT`。

> ⚠ **转向环不在这五道门里**：它有自己的一套（使能门控 + 软限位 + 越限保护 + 目标斜坡），
> 见 `steer_ctrl.c`。**转向电机的输出不受 `duty_limit` / 失联自停约束** ——
> 也就是说链路断了方向盘会**保持原位**，不会松掉。这是有意的（行驶中方向盘松掉更危险）。

## 9. 串口自检

上电第一秒应看到 `[##] UART OK  steer + dual motor speed loop (WiFi)`，之后每秒两行：

```
[    12 s] err=0 online=1 en=0x0006 rx_age=12ms safe=0x0000 int=1 tx=612 | L tgt=0.50 v=0.49 | R tgt=0.50 v=0.50 | cpr=1858/1858 | dL=11 fL=0 gL=0
        STEER tgt=0.00 delta=0.00 err=0.00 duty=0 raw=2157 en=0 flt=1
```

- 只要这行在跳，说明主循环活着、时钟活着、串口活着。
- `online=0` / `safe=0x04` ⇒ 上位机没在发心跳（KartHost 的心跳间隔是 100 ms）。
- `STEER` 行的 `delta` / `err` 单位是**度**；`raw` 是原始读数（中位 ≈ 2157）。
